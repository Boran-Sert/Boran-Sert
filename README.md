### Hakkımda | About Me (TR)

Kocaeli Üniversitesi Bilişim Sistemleri Mühendisliği 4. sınıf öğrencisiyim. Kariyerimi büyük ölçüde **Yapay Zeka (AI)** üzerine inşa ediyorum: yerel LLM'ler üzerinde çalışan otonom ajanlar ve derin öğrenme tabanlı sistemler geliştiriyorum.

Yeni bir sistem kurarken önce onu bir problem gibi ele alıp parçalarına ayırıyorum: darboğaz nerede oluşuyor, hangi varsayım kırılgan, hangi veri yapısı ya da mimari karar en temiz çözümü verir. Bu yaklaşımı somut mühendislik detaylarına dökmeyi seviyorum — bir mikroservis ekosisteminde repository pattern ile dependency injection kurup veritabanı index'leriyle sorgu karmaşıklığını O(log N)'e indirmek gibi.

**Python** ağırlıklı çalışıyorum: FastAPI ile SOLID prensiplerine uygun, gözlemlenebilir (Prometheus/Grafana) backend'ler kuruyorum; Ollama üzerinde çalışan LLM'lerle %100 asenkron, headless multi-agent mimariler geliştiriyorum. Derin öğrenme alanında açıklanabilir (explainable) modeller üzerine araştırma yapıyorum.

Takım çalışmasına yatkınım; üniversite hayatım boyunca farklı ekiplerle görev aldım. Temiz kod (clean code), SOLID prensipleri ve test edilebilir, gözlemlenebilir sistem tasarımı önceliklerim arasında.

### Hakkımda | About Me (EN)

I'm a 4th-year Information Systems Engineering student at Kocaeli University. My career is built largely around **Artificial Intelligence (AI)** — I develop autonomous agents on local LLMs and deep-learning-based systems.

When I start building a new system, I treat it like a problem to break down first: where's the bottleneck, which assumptions are fragile, which data structure or architectural decision leads to the cleanest solution. I like turning that approach into concrete engineering decisions — like wiring up the repository pattern with dependency injection in a microservices ecosystem and cutting query complexity to O(log N) with database indexes.

I mainly work in **Python**: I build SOLID-compliant, observable (Prometheus/Grafana) backends with FastAPI; fully asynchronous, headless multi-agent architectures on local LLMs served via Ollama. In deep learning, I research explainable models.

I work well in teams — I've collaborated with different teams throughout university. Clean code, SOLID principles, and testable, observable system design are priorities for me.
